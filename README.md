# overheadmoney.com

Static site for **The Overhead** — small business money, without the fluff.

- `index.html` — the whole site (no build step, no dependencies beyond Google Fonts)
- `CNAME` — custom domain for GitHub Pages; do not delete
- `og.jpg`, `icon-*.png`, `favicon.ico` — brand assets

Deploys automatically from `main` via GitHub Pages.
